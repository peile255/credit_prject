# 实验设计 / Experimental protocol

## Scope and research questions

One UCI Taiwan credit card default benchmark (30,000 rows). Target is next-month default. Revise the supplied abstract from “multiple benchmark credit-risk datasets” to “a publicly available benchmark credit-risk dataset”; replace the final efficiency assertion with results-supported wording after measuring runtime. This project tests hypotheses, not guarantees of improvement. No external-validation claim.

**RQ1. To what extent does class-weighted stacking ensemble learning improve credit default prediction compared with conventional statistical, machine learning, and ensemble methods?**

**RQ2. How does probability calibration affect the reliability and robustness of credit default risk estimates?**

**RQ3. How stable are the feature-attribution explanations of calibrated ensemble models, and can stability information support more robust constrained counterfactual explanations?**

## Data and leakage control

- Source original workbook retained. ID excluded. 23 original features, binary target 1=default. Preserve documented numeric codes, including unusual but present repayment status codes; SEX, EDUCATION, MARRIAGE treated as categorical and one-hot encoded; remaining features numeric. Median/mode imputation fitted within each training fold. LR numerical features standardized within training. No sample deletion or oversampling. Demographic variables retained for reproducibility; fairness is not established.
- Hash all predictor values to group identical records (including conflicting labels). StratifiedGroupKFold creates five folds; first three train, fourth calibrate/threshold, fifth held-out test. Approximate 60/20/20; actual sizes exported. Ten seeds 42–51. Each configuration shares identical partitions per seed. OOF stacking uses five grouped stratified folds within training; in bootstrap copies of original rows remain in same group. Test never used for fitting, threshold selection, calibration, or candidate generation rules.
- Primary statistical comparison uses split 42. Other splits overlap and are descriptive repeated-split sensitivity, not independent replicates. Model hyperparameters prespecified and fixed (200 trees/iterations where applicable, LR C=1, RF depth=12, XGB depth=4, LGB leaves=31, CAT depth=5; see code for all parameters). No hyperparameter search in main design. Class weights N/(2*N_c) recalculated within every fit. Meta-learner logistic regression trained on three OOF positive-class probabilities, unweighted. Soft voting uses equal mean. Final base models refitted on full training portion.

## RQ1: Predictive performance

14 configurations: LR, RF, XGB, LGB, CAT, VOTE, STACK, each with/without weighting. Main proposed predictor STACK_W. 140 final configuration evaluations across 10 splits (shared fits). AP primary, ROC-AUC secondary; F1, MCC, precision, recall, balanced accuracy at calibration-set maximum-F1 threshold plus 0.5 sensitivity. Paired contrasts STACK_W vs five weighted single models, unweighted STACK, weighted VOTE. Report per-split metrics and repeated split mean/SD. On fixed reference split use 2,000 paired stratified instance bootstraps for AP/AUC differences and percentile 95% intervals. These intervals condition on fitted models and do not adjust for multiplicity. Do not interpret them as unconditional population inference; duplicate groups are not cluster-resampled. Training timer for shared 14-model fit, inference timer per model; no claim of individual training cost or efficiency superiority based on aggregate timing.

## RQ2: Probability reliability

42 configurations per split = 14 predictors x raw/Platt/isotonic, 420 evaluation rows. Fit calibrators exclusively on calibration set with original prevalence. Platt logistic on clipped logit score; isotonic monotone non-decreasing. Primary calibrator predeclared Platt, isotonic comparison. Brier and log loss primary, ECE (10 equal-width bins), calibration slope/intercept, AUC/AP secondary. Same test labels/probabilities used for paired comparison. Strictly monotone calibrators generally preserve ranking, isotonic ties may alter it. Reference split paired stratified bootstrap intervals on STACK_W, STACK, XGB_W, each calibrated vs raw. Risk strata [0,.1), [.1,.2), [.2,.4), [.4,.6), [.6,1], report counts, mean predicted risk, actual default frequency and Wilson intervals; no bank approval meaning. Missing-feature robustness: 0/5/10/20% independent cell masking with identical masks across compared models, frozen models and calibrators, training imputers. Report AP/AUC/Brier/ECE, not simulated real temporal shift. Additional training-sample robustness compares raw/Platt/isotonic weighted stacking over 30 development and 10 held-out bootstrap fits.

## RQ3: Stability-aware explanations

Five configurations: XGB_W, STACK, STACK_W, STACK_W_PLATT, STACK_W_ISO. Main contrasts: STACK_W vs XGB_W (weighted ensemble vs weighted single model), STACK_W vs STACK (weighting), STACK_W_PLATT/ISO vs STACK_W (calibration), and Platt vs isotonic. 30 common training bootstrap samples on split 42. Seeds vary along with samples, so stability includes both resampling and training randomness. Additional 10 training bootstraps for STACK_W_PLATT held out from stability labels and candidate ranking, but share original train/calibration/test data; not independent external data.

Local explanations: select up to 20 instances in each TP/TN/FP/FN stratum of fixed STACK_W_PLATT reference model using calibration-derived threshold, same IDs across configurations. Global explanation sample: 100 uniformly sampled test instances (not balanced). Counterfactual sample: up to 100 reference high-risk cases. Union explained (at most 280 IDs). Exact original feature dimensions, common 16 training background rows, four random permutations and their reverse per run. Compute marginal contributions along paths from background to instance, average, explain complete probability function including calibration; test local additivity. This is a Monte Carlo approximation to interventional Shapley values, not exact conditional SHAP; correlated predictors can lead to unrealistic masked combinations. Sensitivity on up to 10 reference instances uses 4/8/16 permutation cycles and reports overlap, absolute contribution differences and runtime. If convergence is poor, decide a higher budget using development-only pilot before final study; do not change after looking at final outcomes.

Compute pairwise Top-K overlap (K=5, sensitivity 3/10), Spearman ranks of absolute SHAP, common top-K sign agreement excluding |phi|<=1e-6 (report coverage), normalized attribution SD. First aggregate pairs within each instance, then report instances. Global mean absolute attributions and 2.5/97.5% empirical resampling quantiles. Stability-aware summary per instance-feature: mean signed contribution, top-K selection frequency, dominant nonzero direction fraction across all replicates, empirical quantiles. High if freq>=.8 and direction>=.9; Moderate if freq>=.5 and direction>=.7; else Low. These are study thresholds. Validate with selection frequencies/directions from ten held-out retrained models. Small bootstrap count means quantiles approximate uncertainty, not precise inferential CI. Fixed background isolates one source of explanation variability. Raw magnitudes may change when calibration rescales probabilities; focus on rank/overlap and normalized SD.

Counterfactual scenario: only LIMIT_BAL can vary (hypothetical lender-controlled policy change), all demographic and historical variables frozen. Candidate grid +/-30% of original limit, clipped to train 1st–99th percentile, rounded to NT$1000. No historical payment rewriting. Model-valid if probability below fixed calibration-set reference threshold. This is a restricted scenario search, not DiCE, causal recourse, or a guarantee of practical feasibility. Candidate set shared across methods. Nearest = smallest relative limit change; Robust = highest fraction of development bootstrap models meeting same target, then proximity; StabilityGatedRobust = Robust but abstain unless credit-limit attribution has High stability. The gate is an abstention strategy rather than a separate optimization algorithm; test whether it identifies higher conditional robustness, while reporting coverage penalty and unconditional robustness (failure counts as zero). Held-out 10 models evaluate candidates, not used for search. Report coverage, validity, constraint feasibility, proximity, unconditional and conditional robust validity. All generated solutions modify one variable; sparsity is constant. A negative finding or zero coverage is a legitimate result. No unsupported causal or actionable claim.

## Statistical interpretation and output plan

Primary RQ1/RQ2 effect sizes and conditional paired bootstrap intervals; no formal p-values for those contrasts. RQ3 instance-level paired Wilcoxon tests with Holm correction separately across stability and counterfactual families; paired mean differences and instance-level percentile bootstrap intervals. These are exploratory, conditional on fixed fitted model sets; repeated pairs and repeated seeds are not independent. Balanced local samples are not prevalence representative. Conditional CF robustness must be read together with coverage. Eight automatically produced tables plus additional statistics and risk bands; eight PNG/PDF figures (performance, ROC/PR, calibration, missing robustness, global SHAP, stability, counterfactual, local SHAP). Data partitions, bootstrap IDs, reference probabilities, full explanation arrays and package versions exported for traceability. All manuscript result fields must be filled only after full execution.
